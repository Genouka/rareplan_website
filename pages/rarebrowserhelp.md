# Rare浏览器在线帮助

ℹ️RarePro浏览器 完整使用指南

如果您使用的是Rare浏览器，可能有部分功能缺失，购买收费版后解锁。

最新版本官方使用教程视频请访问：
https://www.bilibili.com/video/BV1pzZJB6Evw/

═══════════════════════════════════
【一、主页面功能】
═══════════════════════════════════

主页面是您启动应用后看到的第一个界面，包含以下功能按钮：

* 浏览 — 打开网页浏览器。如果启用了搜索中间页，会先显示搜索框；否则直接打开主页。
* 下载 — 查看和管理已下载的文件。
* 历史 — 查看浏览历史记录，支持按标题、时间、访问次数排序。
* 收藏 — 查看和管理书签收藏。
* 设置 — 进入应用设置页面。
* 帮助 — 显示本帮助文件。
* 更新日志 — 查看版本更新记录。
* 开源许可 — 查看第三方开源库许可。
* 隐私政策 — 查看隐私保护协议。
* 用户协议 — 查看最终用户许可协议。
* 清理后台 — 清理后台进程释放内存（Pro版功能）。
* 退出 — 关闭应用。

═══════════════════════════════════
【二、浏览页面功能】
═══════════════════════════════════

浏览页面是您浏览网页时的核心界面。点击顶部时钟区域可以打开浮动菜单。

▶ 菜单顶部操作：
* 隐藏菜单[回启动页] — 隐藏菜单返回网页。长按可关闭当前Activity。
* +新标签 — 新建一个空白标签页。
* 标签列表 — 查看所有打开的标签页，可切换或新建标签。旁边数字显示当前标签数量。
* 网络设置 — 进入系统无线网络配置。
* 清理内存 — 清理后台进程。
* 收藏 — 将当前网页添加到书签。
* 资源嗅探 — 嗅探网页中的媒体资源（Pro版）。
* 二维码 — 生成当前网页URL的二维码。

▶ 导航操作：
* 刷新 — 重新加载当前页面。长按强制刷新（类似Ctrl+F5）。
* 后退 — 返回上一页。
* 前进 — 前往下一页。
* 复制URL — 复制当前网页地址到剪贴板。

▶ 网址输入：
* 在输入框中输入网址或搜索内容，点击"前往"按钮加载。
* 长按"前往"按钮可清空输入框。

▶ 缩放控制：
* 启用强制缩放 — 开关强制缩放功能，通过JS zoom实现。
* 缩放滑块 — 拖动调整缩放倍率（50=1.00倍）。
* 长按"启用强制缩放"文字可恢复默认缩放。
* 普通缩放按钮 — 放大/缩小/默认（建议使用强制缩放）。

▶ 高级功能：
* 停止加载 — 终止当前页面加载。
* 远程调试 — 启用Chrome远程调试。长按关闭。（Pro版）
* JS插件 — 打开油猴脚本设置界面（Gecko内核）/ JS插件管理页面。
* 修改UA — 更改User-Agent字符串。（Pro版）

▶ 开关设置：
* 保持屏幕常亮 — 防止屏幕自动关闭。
* 禁用JS — 关闭JavaScript执行。
* 无图模式 — 停止自动加载图片。
* 网站设置 — 为当前网站配置独立设置（详见第五节）。

▶ 不常用功能：
* 宽视图模式 — 切换UseWideViewPort设置。
* 忽略证书错误 — 跳过SSL证书验证（慎用）。
* 屏幕状态设定 — 竖屏/横屏/自动旋转/圆屏外衬。
* 缓存 — 点击保存网页HTML。长按查看网页源码。

【三、多标签页功能】
═══════════════════════════════════

RarePro支持多标签页浏览，让您可以同时打开多个网页：

* 新建标签 — 在菜单中点击"+新标签"按钮创建空白标签页。
* 标签列表 — 点击"标签列表"按钮查看所有已打开的标签页。
  - ● 标记表示当前活动标签
  - ○ 标记表示后台标签
  - 点击标签名可切换到该标签
  - 可在标签列表中新建标签
* 标签计数 — 菜单中显示当前打开的标签数量。
* 关闭标签 — 关闭最后一个标签时会退出浏览页面。

【四、设置页面】
═══════════════════════════════════

设置页面分为以下类别：

▶ 个人信息：
* 查看激活状态 — 查看Pro版授权状态。
* 你同意过的协议 — 查看已同意的协议列表。
* 加载公告/检查更新 — 手动检查更新（Pro版）。
* 允许上报崩溃日志 — 控制Bugly崩溃上报。

▶ 主页面功能：
* 仅关闭浏览器 — 关闭时不清理内存。
* 程序启动密码保护 — 设置图案锁屏密码。

▶ 浏览页面功能：
* 浏览菜单默认值 — 设置新打开网页时的默认开关状态：
  - 默认启用JavaScript
  - 默认加载图片
  - 默认宽视图模式
  - 默认启用强制缩放
  - 默认保持屏幕常亮
  - 默认忽略证书错误
* 网站独立设置管理 — 管理所有已配置的网站独立设置。
* 使用旧版浏览菜单 — 切换到旧版菜单布局（不推荐）。
* 保留上次资源嗅探结果
* 启用搜索中间页 — 打开浏览时先显示搜索框。
* 强制缩放实时预览 — 拖动缩放滑块时实时预览效果。
* 更宽的标题栏 — 增大顶部点击区域。
* 网页滚轮兼容模式 — 改善手表旋转表冠滚动体验。
* 默认启用圆屏外衬 — 圆屏手表自动添加圆角边距。
* 小白条 — 底部可拖拽控制器（WIP）。

▶ 网页引擎：
* 渲染核心管理 — 选择网页渲染内核（Crosswalk/WebView/X5/Gecko等）。
* 切换搜索引擎 — 选择默认搜索引擎（必应/百度/360/秘塔/谷歌）。
* Polyfill — 提高Crosswalk内核兼容性（Pro版）。
* 无痕模式 — 不记录浏览历史（WIP）。
* 内嵌下载管理器 — 使用内置下载管理。

▶ 广告拦截（WIP）：
* 目前仅对Crosswalk核心生效。

▶ 开发者调试选项：
* 仅供调试使用，普通用户请勿操作。

【五、网站独立设置】
═══════════════════════════════════

您可以为每个网站配置独立的浏览设置，优先级高于全局默认值：

▶ 在浏览页面设置：
1. 打开菜单，点击"网站设置"按钮。
2. 在弹出的对话框中勾选/取消各项设置。
3. 点击"保存并应用"立即生效。
4. 点击"重置为默认"可删除该网站的独立配置。

▶ 在设置页面管理：
1. 进入设置 → 浏览页面功能 → 网站独立设置管理。
2. 查看所有已配置的网站列表。
3. 点击某个网站可编辑其配置。
4. 可删除不再需要的网站配置。

▶ 可配置项：
* 启用JavaScript — 是否允许该网站执行JS。
* 加载图片 — 是否自动加载该网站的图片。
* 宽视图模式 — 是否对该网站使用宽视口。
* 启用强制缩放 — 是否对该网站启用强制缩放。
* 保持屏幕常亮 — 浏览该网站时是否保持屏幕常亮。
* 忽略证书错误 — 是否忽略该网站的SSL证书错误。

【七、渲染内核】
═══════════════════════════════════

RarePro支持多种网页渲染内核：

| 内核 | 说明 |
|------|------|
| Crosswalk (XWalk) | 经典内核，兼容性好，32位支持 |
| 系统WebView | 使用系统自带WebView |
| 升级版WebView | 从服务器下载更新版WebView |
| 腾讯X5/TBS | 腾讯浏览服务内核 |
| GeckoView | 基于Firefox的Gecko引擎，支持油猴脚本 |
| GenOuka核心 (Html4View) | 自研文本渲染核心 |

不同内核的功能支持程度不同，如遇兼容问题请尝试切换内核。

【十、常见问题】
═══════════════════════════════════

Q: 网页无法正常显示？
A: 尝试切换渲染内核，或启用Polyfill（Crosswalk内核）。

Q: 手表上操作不方便？
A: 启用"更宽的标题栏"和"网页滚轮兼容模式"。

Q: 如何节省流量？
A: 开启"无图模式"和广告拦截。

Q: 某些网站JS导致卡顿？
A: 可为该网站单独禁用JS，或在菜单中临时关闭JS。

Q: 圆屏手表显示异常？
A: 确保启用了"默认启用圆屏外衬"选项。

Q: 如何为特定网站设置不同配置？
A: 在浏览该网站时点击菜单中的"网站设置"按钮，或在设置页面的"网站独立设置管理"中配置。
