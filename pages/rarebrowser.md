## 软件功能介绍

### 浏览核心功能
* **多标签页浏览** — 同时打开多个网页，支持标签列表切换、新建/关闭标签
* **多种渲染内核** — 支持6种内核切换（详见下方内核部分）
* **网站独立设置** — 为每个网站配置独立的JS/图片/缩放/常亮/证书等设置
* **强制缩放** — JS zoom实现任意网页强制缩放，支持滑块实时预览
* **搜索引擎切换** — 必应/百度/360/秘塔AI/谷歌
* **搜索中间页** — 打开浏览时先显示搜索框
* **无痕模式** — 不记录浏览历史（WIP）
* **广告拦截** — 基于js规则加载（WIP）

### 多渲染内核架构

| 内核 | 说明 |
|------|------|
| Crosswalk 内核 | 经典内核，流畅简单 |
| 系统WebView | 使用系统自带WebView |
| 升级版WebView | 从服务器下载更新版WebView |
| 腾讯X5/TBS | 腾讯浏览服务内核 |
| GeckoView (新默认核心) | 基于Firefox Gecko引擎，支持油猴脚本(Violentmonkey) |
| GenOuka核心 | 自研实验性文本渲染内核 |

### 下载与媒体
* **内嵌下载管理器** — 支持下载文件管理、删除确认、文件属性查看
* **资源/视频嗅探** — 嗅探网页中的媒体资源链接（Pro版）
* **视频解析与播放** — 支持调用凉腕播放器、腕上视频等外部播放器
* **长按图片保存** — 保存网页图片到本地

### 书签与历史
* **收藏/书签管理** — 添加、搜索、清理收藏，支持导入导出
* **历史记录** — 按标题/时间/访问次数排序，支持搜索、批量清理
* **浏览次数累加** — 重复访问同一页面累加计数

### 安全与隐私
* **图案锁屏密码** — 程序启动密码保护
* **忽略证书错误** — 可跳过SSL验证（慎用）

### WearOS手表适配
* **圆屏外衬** — 圆屏手表自动添加圆角边距
* **滚轮适配** — 支持手表旋转表冠滚动网页
* **WearOS专用对话框**
* **更宽的标题栏** — 增大顶部点击区域
* **小白条菜单** — 底部可拖拽控制器（实验性）

### 其他功能
* **二维码生成与识别** — 生成当前URL二维码，识别二维码图片中的网址
* **远程调试** — Chrome远程调试支持（Pro版）
* **修改UA** — 自定义User-Agent（Pro版）
* **屏幕旋转/常亮** — 竖屏/横屏/自动旋转/常亮
* **缓存/源码查看** — 保存网页HTML，查看网页源码
* **Polyfill自动注入** — 提高Crosswalk内核兼容性
* **清理后台** — 一键清理后台进程释放内存
