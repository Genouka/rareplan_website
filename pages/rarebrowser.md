## 多渲染内核架构

<div class="product-table-wrapper" markdown="1">

| 内核 | 说明 |
|------|------|
| Crosswalk 内核 | 经典内核，流畅简单 |
| 系统WebView | 使用系统自带WebView |
| 升级版WebView | 从服务器下载更新版WebView |
| 腾讯X5/TBS | 腾讯浏览服务内核 |
| GeckoView（新默认核心） | 基于Firefox Gecko引擎，支持油猴脚本 |
| GenOuka核心 | 自研实验性文本渲染内核 |

</div>
