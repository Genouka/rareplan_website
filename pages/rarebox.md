# RareBox

你当前查看的是适用于手机和手表的应用。如果你需要电脑版本请点击<a href="/rareboxdesktop/">这里</a>

**你没有走错！这就是RareBox新版官方页面**

RareBox是一款面向Android设备和Wear OS智能手表的强大ADB工具箱，由开发者秋冥散雨_GenOuka精心打造。它不仅支持通过ADB协议远程连接设备，还集成了Shizuku、Dhizuku、Root、Zygote漏洞等多种命令执行后端，让您无需电脑也能轻松管理Android设备。本软件完全**免费开源**。

## 目前支持并适配的设备
* Android系统手表（部分手表仅能远程调试其他手表）
* WearOS系统手表（包括问问、小米等品牌在内大部分手表可以自我调试，所有手表都可以远程调试其他手表）
* 部分华为手表（部分可以自我调试，所有手表都可以远程调试其他手表）
* 其他类型支持adb调试的电子设备
* Android系统手机（都可以远程调试其他手表）
* 鸿蒙系统手机（都可以远程调试其他手表）

注：自我调试指的是可以直接安装到手表上使用。远程调试指的是可以通过在一台设备上安装调试另一台设备。

## 连接方式

| 连接方式 | 说明 | 要求 |
|----------|------|------|
| 新ADB方案（推荐） | TLS加密连接，支持无线配对 | Android 11+ |
| 旧ADB方案 | 传统RSA认证连接 | 兼容所有Android版本 |
| OTG模式 | USB OTG线直接连接 | 本机支持USB Host |
| 免配对连接 | 利用系统漏洞绕过配对认证 | 特定场景 |

还支持**扫描局域网设备**（mDNS自动搜索）功能。

## 命令后端

| 后端 | 说明 | 要求 |
|------|------|------|
| ADB | 通过网络连接远程设备执行命令 | 需先建立ADB连接 |
| Shizuku | 通过Shizuku服务在本机执行命令 | 需安装并启动Shizuku |
| Dhizuku | 通过Dhizuku(Device Owner)执行命令 | 需设备已激活Dhizuku |
| Root | 通过Root权限执行命令 | 设备需已Root |
| Zygote漏洞 | 利用CVE-2024-31317漏洞提权执行 | 需Shizuku/Dhizuku/Root作为前置 |
| WriteSecure | 修改系统安全设置 | 需通过其他后端授权 |

## 软件功能介绍

### 安装软件
将APK软件包安装到目标设备，支持指定安装位置和安装原因等高级选项，华为手表可勾选「华为模式」安装。

### 常用终端命令
提供预设的ADB Shell命令快捷入口，包括激活Shizuku、修改/重置屏幕尺寸、修改/重置DPI、修改/重置显示范围、设置屏幕旋转、查看电池信息等。

### ADB终端
完整的ADB Shell命令行终端，支持命令历史记录、Ctrl+C中断、自动/手动滚动切换、粘贴和换行输入。

### 传输文件
在本机和目标设备之间推送/拉取文件。

### 圆屏改方显示
调整目标设备的显示比例和DPI，特别适用于圆形屏幕手表改为方形显示。支持Overscan模式和wm size模式，支持1:1、16:9、9:16、4:3、3:4等比例。

### 文件管理
浏览和管理本机及远程设备文件，支持浏览目录、新建文件夹、重命名、删除、复制/移动、查看属性、推送/拉取文件、打开本机文件、符号链接解析。

### 应用管理
管理设备上安装的应用程序，支持查看应用列表（搜索筛选）、启用/停用应用、卸载应用（含系统应用）、清除应用数据、提取APK安装包、编辑应用权限、查看应用属性。支持全部/系统/第三方/已停用/已启用筛选。

### 系统设置
浏览和打开Android系统设置项，支持手机设置和手表设置，搜索快速定位。

### 密钥管理
管理ADB连接认证密钥，支持导出公钥、导出密钥对、导入密钥对、重新生成密钥、查看密钥信息。

### 跨设备密钥交换
通过局域网在两台设备之间交换ADB密钥，实现免配对连接。

### 设备信息
查看本机详细信息，包括设备基本信息、系统信息、CPU信息、屏幕信息、内存信息、存储信息、网络信息、应用信息。

### 远程屏幕控制
远程查看和控制目标设备屏幕，支持实时屏幕画面传输、触摸事件传递、导航按钮、可配置码率和最大分辨率、仅查看模式、沉浸式全屏体验。

### 属性操作
读取和修改Android系统属性（getprop/setprop），支持ro.、persist.、sys.、debug.等常用属性前缀。

### 屏幕形状
设置界面适配模式（圆屏/方屏/自动），优化圆屏或方屏设备的显示效果。
